Power cable 선택 기준 수정
Power cable은 선택한 모터의 시리즈·용량·프레임을 기준으로 결정합니다.
드라이브 용량은 호환 가능 여부에만 사용하며, 같은 모터를 선택한 상태에서 드라이브 용량만 변경해도 Power cable 품번은 바뀌지 않습니다.
Power cable 표기 순서
모든 드라이브의 1 kW 이상 Power cable은 기본 품번 + 길이 + 가동/비가동 + kW 순서로 표시합니다.
예: ACS3-CAPW3105-N-1.5, ACS3-CAPW3105-A-1.5
1 kW는 -1, 1.5 kW는 -1.5, 2 kW는 -2처럼 표기합니다.
B2 드라이브 케이블 표기 규칙
B2 Encoder: 1 kW 미만은 ASD-B2EN00XX, 1 kW 이상은 ASD-B2EN10XX로 표기합니다.
예: 3 m 비가동형 → ASD-B2EN0003-N / ASD-B2EN1003-N
가동형은 다른 케이블과 동일하게 -A, 비가동형은 -N을 붙입니다.
B2 Power cable은 A2 드라이브 Power cable과 동일한 명칭 체계를 사용합니다.

호환성: B2 드라이브 + A2/A3/B3 모터는 조합 불가 상태를 유지합니다.
A2 드라이브 케이블 DB
A2 Power / Encoder 케이블도 셀렉터 공통 표기 규칙을 적용합니다.
-A = 가동형 / -N = 비가동형
예: ASD-ABPW0003-N, ASD-ABPW0003-A, ASD-CAEN1003-N, ASD-CAEN1003-A
B2 Power cable도 A2 Power cable과 동일한 명칭 체계 및 동일한 -A/-N 표기를 사용합니다.
A3 선택 시 A2 파워케이블 참조 표시
A3 드라이브 + A2/B2 모터 선택 시 Power 결과 뒤 괄호에 A2 매뉴얼 기준 파워케이블을 함께 표시합니다.
예: ACS3-CAPW1203-1.5-N (A2: ASD-CAPW1003)
A2 매뉴얼에서 확인되는 표준 완제품 길이는 3 m / 5 m 기준이며, 모터측 커넥터가 같은 그룹인 경우의 참조값입니다.
Encoder type 표기 수정
Incremental → CAEN 계열
Absolute → CAEA 계열
케이블 타입 suffix는 기존 규칙대로 -A = 가동형, -N = 비가동형입니다.
예: Incremental 3 m 가동형 → ACS3-CAEN1003-A / Absolute 3 m 가동형 → ACS3-CAEA1003-A
Power cable 용량 suffix 추가
Power cable 품번의 용량 표기는 1 kW 초과 모터에만 붙입니다.
예: 0.75 kW / 1 kW → 용량표기 없음, 1.5 kW 비가동형 → …-1.5-N, 2 kW 가동형 → …-2-A
Encoder cable에는 용량 suffix를 붙이지 않습니다.
B3 드라이브 DB 추가
ASDA-B3 매뉴얼 Appendix B 기준으로 B3 power/encoder cable family를 추가했습니다.
F80 이하: Power 31XX / Brake 41XX / Encoder 10XX
F100~F130: Power 32XX / Brake 42XX / Encoder 27XX
F180: Power 34XX / Brake 44XX / Encoder 27XX
표시는 기존 요청대로 CAPW / CAEN + -A(가동형), -N(비가동형) 규칙을 사용합니다.
사내 케이블 품번 표기 규칙
Power cable: ACS3-CAPW…-A = 가동형 / ACS3-CAPW…-N = 비가동형
Encoder cable: ACS3-CAEN…-A = 가동형 / ACS3-CAEN…-N = 비가동형
예: ACS3-CAPW1003-A (가동형), ACS3-CAPW1003-N (비가동형)
모델명 기준
A2: ECMA-C10401…, ECMA-E11315… 형식
B2: ECMA-C20401…, ECMA-E21315… 형식
B3: ECM-B3L-C20401RS1, ECM-B3M-E21315RS1처럼 B2 용량코드 계열에 B3 사양코드가 추가되는 형식.

※ 모터 모델명은 브레이크/축/오일실 suffix를 제외한 기본 형식으로 표시하며, 케이블 선정은 정격·프레임·세대 connector group을 기준으로 합니다.
